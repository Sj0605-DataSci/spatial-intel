🎅 World-Model Benchmark — Santa's Gift Journey

Can a diffusion model act as a game world model — given a frame + an action, produce the next frame? We benchmark methods on speed, action-correctness (is Santa 'S' on the right cell?), and image quality (VLM-judged).

The task: An 8×8 Christmas grid game. The player is the red S badge, starting at cell (1,1). An action like "move right" should move S one cell. We compare ways to generate the next frame. Grid geometry solved: cell = 87.5px, cell (1,1) center at pixel (227,227).

🔬 Takeaways

  1. Cut-paste dominates for actor moves: 100% accurate, 1 ms, best quality. No model needed.
  2. Diffusion hurts here: full-inpaint corrupts the static scene; even hybrid (inpaint only the hole) is 300×+ slower with a correctness regression.
  3. Plain img2img (sd-turbo) is not an editor: it regenerates the whole scene and ignores the move. Need true instruction-edit models (FLUX-Kontext, Qwen-Image-Edit) — benchmarking next.
  4. The real research question: can ANY small edit model match cut-paste's 100%/1ms, or is deterministic sprite-logic simply the right tool and diffusion reserved for initial scene gen?
